    Quick free hosting options (choose one):
    1) GitHub Pages (simple static site)
       - Create a GitHub repo, push these files to the `main` branch (or `gh-pages`).
       - In repo Settings -> Pages -> Source select branch and folder (`/ (root)`).
       - If SPA uses pushState routing, add a `404.html` that redirects to `index.html`.

    2) Netlify (static with redirects)
       - Create a Netlify account, drag & drop the project folder into the Netlify UI, or connect your GitHub repo.
       - If SPA routing required, create a file `_redirects` with:
         /*    /index.html   200

    3) Vercel (good for Node/Next or static)
       - Create a Vercel account, import from GitHub repo.
       - For static sites, it will detect and deploy automatically.

    4) Cloudflare Pages
       - Create a Pages project and connect to your GitHub repo.
       - Configure build settings if necessary (or leave blank for static).

    5) Surge.sh (simple CLI static hosting)
       - Install surge (`npm i -g surge`), then `surge ./ public-url.surge.sh`.
